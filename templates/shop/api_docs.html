Documentación de la API de Ferremas

Esta página proporciona información básica sobre cómo utilizar la API de Ferremas. Para una documentación interactiva completa, visite la documentación Swagger.

Introducción

La API de Ferremas permite acceder a información detallada de productos, categorías y subcategorías. Está diseñada para ser utilizada tanto por sucursales internas como por tiendas externas.

Base URL: https://ferremas.cl/api/v1/

Autenticación

La API requiere autenticación mediante token. Para obtener un token:

POST /api/v1/token/

Cuerpo de la solicitud:

{
  "username": "su_usuario",
  "password": "su_contraseña"
}

Respuesta:

{
  "token": "su_token_de_autenticación"
}

Incluya el token en el encabezado de todas las solicitudes:

Authorization: Token su_token_de_autenticación

Endpoints Principales

Productos

GET /api/v1/productos/ - Listar todos los productos
GET /api/v1/productos/{id}/ - Obtener detalles de un producto específico
GET /api/v1/productos/low_stock/ - Listar productos con stock bajo
GET /api/v1/productos/out_of_stock/ - Listar productos sin stock
GET /api/v1/productos/by_code/?code=CODIGO - Buscar producto por código

Categorías

GET /api/v1/categorias/ - Listar todas las categorías
GET /api/v1/categorias/{id}/ - Obtener detalles de una categoría específica
GET /api/v1/categorias/{id}/subcategories/ - Listar subcategorías de una categoría
GET /api/v1/categorias/{id}/products/ - Listar productos de una categoría

Subcategorías

GET /api/v1/subcategorias/ - Listar todas las subcategorías
GET /api/v1/subcategorias/{id}/ - Obtener detalles de una subcategoría específica
GET /api/v1/subcategorias/{id}/products/ - Listar productos de una subcategoría

Filtrado y Búsqueda

La API permite filtrar y buscar productos:

GET /api/v1/productos/?search=taladro - Buscar productos que contengan "taladro"
GET /api/v1/productos/?subcategory__category=1 - Filtrar productos por categoría
GET /api/v1/productos/?subcategory=2 - Filtrar productos por subcategoría
GET /api/v1/productos/?ordering=price - Ordenar productos por precio (ascendente)
GET /api/v1/productos/?ordering=-price - Ordenar productos por precio (descendente)

Ejemplos de Uso con Python

Ejemplo de cómo usar la API con Python:

import requests

# Obtener token de autenticación
auth_url = "https://ferremas.cl/api/v1/token/"
auth_data = {
    "username": "su_usuario",
    "password": "su_contraseña"
}
response = requests.post(auth_url, data=auth_data)
token = response.json().get("token")

# Establecer encabezado de autenticación
headers = {
    "Authorization": f"Token {token}"
}

# Obtener lista de productos
products_url = "https://ferremas.cl/api/v1/productos/"
response = requests.get(products_url, headers=headers)
products = response.json()

# Imprimir detalles de los productos
for product in products:
    print(f"ID: {product['id']}")
    print(f"Código: {product['code']}")
    print(f"Nombre: {product['name']}")
    print(f"Precio: {product['price']}")
    print(f"Stock: {product['stock']}")
    print(f"Categoría: {product['subcategory']['category']['name']}")
    print(f"Subcategoría: {product['subcategory']['name']}")
    print(f"Descripción: {product['description']}")
    print(f"URL de imagen: {product['image_url']}")
    print("-" * 40)
